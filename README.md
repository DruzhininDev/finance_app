# Finance App

Приложение для учёта личных финансов.

## Возможности
- Добавление доходов и расходов
- Просмотр истории операций
- Подсчёт текущего баланса

## Технологии
- Python
- Flask
- SQLite

## Запуск
1. Установить зависимости: `pip install flask`
2. Запустить: `python app.py`
3. Открыть: http://127.0.0.1:5000
